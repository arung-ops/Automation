# Playwright Framework

This project is a simple Playwright test automation framework created to match the reference structure.

## Structure

- `tests/` – test cases
- `pages/` – page object models
- `fixtures/` – shared test setup utilities
- `utils/` – constants, data, helper functions
- `locators/` – locator definitions
- `config/` – environment configuration
- `test-data/` – JSON inputs
- `reports/` – HTML and execution reports
- `screenshots/` – failure screenshots

## Run tests

```bash
npm install
npx playwright test
```
